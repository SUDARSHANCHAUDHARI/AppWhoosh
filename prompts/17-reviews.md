# PROMPT 17 — Review Responder (AI-Powered)

## Context
Play Store reviews affect ranking. Responding to 1-3 star reviews improves
conversion and sometimes gets users to update their rating.
Claude drafts professional responses; I approve before publishing.

## Your tasks

1. Create `tools/reviews.js`:

   `fetchReviews(appId, options)`:
   - Use Google Play Developer API:
     `GET /androidpublisher/v3/applications/{package}/reviews`
   - Filter options: `{ rating: 1|2|3|4|5, unanswered: true, limit: 50 }`
   - Return array:
     ```json
     [
       {
         "reviewId": "abc123",
         "author": "John D.",
         "rating": 2,
         "text": "App crashes on startup",
         "date": "2025-01-01",
         "replied": false,
         "replyText": null
       }
     ]
     ```

   `draftReply(review, appContext)`:
   - Call Claude API:
     ```
     You are a professional app developer responding to a Play Store review.
     App: {appName} by SudarshanTechLabs
     Review ({rating} stars): "{reviewText}"
     Rules:
     - Be empathetic and professional
     - Max 350 characters
     - Acknowledge the issue specifically
     - Offer a solution or ask for more info
     - Don't be defensive
     - End with: "- SudarshanTechLabs Team"
     Return ONLY the reply text.
     ```
   - Return draft reply string

   `publishReply(appId, reviewId, replyText)`:
   - POST to Play Developer API:
     `POST /androidpublisher/v3/applications/{package}/reviews/{reviewId}:reply`
   - Body: `{ replyText }`

   `batchDraftReplies(appId, maxRating)`:
   - Fetch all unanswered reviews with rating ≤ maxRating
   - Draft a reply for each using Claude
   - Return array of `{ review, draft }`

2. Create interactive review CLI flow:

   `appwhoosh reviews <app-id>`:
   - Fetch unanswered reviews sorted by rating (lowest first)
   - For each review, show:
     ```
     ────────────────────────────────
     ★★☆☆☆ John D. — Jan 1, 2025
     "App crashes on startup every time I try to open it."

     Draft reply:
     "Hi John, we're sorry to hear about the crash! Please try
     clearing the app cache in Settings → Apps → [App] → Clear Cache.
     If the issue persists, email us at sudarshantechlabs@gmail.com
     with your device model. - SudarshanTechLabs Team"

     [S]end  [E]dit  [S]kip  [Q]uit
     ```
   - User presses key to send, edit, skip, or quit
   - If Edit: open in $EDITOR or prompt for new text
   - Track sent replies in `~/.appwhoosh/replies.json`

3. Add CLI commands:
   - `appwhoosh reviews <app-id>` — interactive review responder
   - `appwhoosh reviews <app-id> --rating 1,2,3` — filter by rating
   - `appwhoosh reviews <app-id> --draft-all` — draft replies for all, save to file
   - `appwhoosh reviews <app-id> --export` — export reviews to CSV
   - `appwhoosh reviews all --rating 1,2` — respond to 1-2 star reviews across all apps

4. Add to `mcp/tools.js`:
   - Tool: `fetch_reviews` — input: `{ app_id, max_rating, limit }`
   - Tool: `draft_reply` — input: `{ app_id, review_id, review_text, rating }`

5. Create `~/.appwhoosh/reply-templates.json`:
   - Common reply templates for typical issues:
     - Crash: "We're sorry about the crash! Please try clearing cache..."
     - Ads: "The app is completely ad-free! Please update to the latest version..."
     - Feature request: "Thank you for the suggestion! We'll consider it..."
   - Claude uses these as context when drafting to keep tone consistent

## Done when
- `appwhoosh reviews myfamilytracker` fetches real reviews and shows interactive flow
- Draft replies are generated by Claude API
- [S]end actually publishes the reply to Play Store
- `appwhoosh reviews myfamilytracker --draft-all` saves drafts to a file for review
